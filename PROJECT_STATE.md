# GameHubParty - состояние проекта

Последнее обновление: 12.07.2026

Текущая версия: `v0.5.0` — новая графика и магазин-воронка. Полный аудит готовности: `design/RELEASE_AUDIT.md`.

## Статус MVP

MVP готов к финальной приемке и мягкому публичному запуску после свежего деплоя и проверки production-сценариев.

Работают:

- Шпион: комнаты, роли, таймер, голосование, ответ шпиона, режим предметов, несколько шпионов, словари и свои локации.
- Alias: комнаты, команды, раунды, очки, платные наборы слов.
- Бункер: карточки персонажей, сценарии, режим личной карточки, публичное вскрытие, обсуждение и голосование.
- Профиль: гостевой профиль, email-аккаунт, аватар, имя, история игр, покупки и активные доступы.
- Магазин: WeekendPass, Game Pass для Шпиона/Alias/Бункера, PRO, тема PartyHub.
- YooKassa: платежная ссылка, возвращение на сайт после оплаты, webhook, проверка суммы/статуса и автоматическая выдача доступа.
- Админка `/admin`: активные комнаты, заказы, зарегистрированные игроки, поиск, выдача и отзыв доступов.
- Обратная связь: форма в меню, серверное сохранение и отправка на `support@gamehubparty.ru`.
- Реклама: внутренние рекламные слоты и правило отключения рекламы для комнаты при активном платном доступе.

## Платежи

YooKassa считается рабочей интеграцией, а не заготовкой:

- заказ создается только для email-аккаунта;
- сервер создает платеж в YooKassa;
- пользователь возвращается на `/store?order=...` после оплаты;
- сайт синхронизирует статус заказа после возвращения с платежной страницы;
- webhook `/api/yookassa/webhook` подтверждает успешные и отмененные платежи;
- доступ открывается только после успешной оплаты или ручного админского подтверждения.

Локальное demo-подтверждение нужно только для разработки и автотестов. В production обычный пользователь не должен подтверждать заказ без платежа.

## Финальная проверка перед релизом

1. Убрать явный системный и временный мусор из корня проекта.
2. Проверить, что `README.md`, `PROJECT_STATE.md`, `FINANCE.md`, `LEGAL.md` не спорят с фактическим кодом.
3. Прогнать `npm.cmd test`.
4. Прогнать `npm.cmd run build`.
5. Прогнать `npm.cmd run test:auto`.
6. Проверить мобильные экраны около `390px`: главная, магазин, профиль, Шпион, Alias, Бункер, лобби, роль, обсуждение, голосование.
7. Проверить, что на сайте нет битого mojibake-текста, внутренних черновиков, случайных demo-обещаний и горизонтального скролла.
8. После деплоя проверить `https://gamehubparty.ru/api/health`, версию на сайте, YooKassa checkout, возвращение с платежной страницы, webhook и выдачу доступа.
