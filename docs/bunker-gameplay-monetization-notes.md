# Бункер: прогон, правки и монетизация

Дата: 30.06.2026

## Что проверено

- Режим "телефон на стол": игрок открывает карточку у себя, нажатием выбирает видимые поля, может показать экран компании или положить телефон на стол.
- Режим "вскрытие по очереди": текущий игрок раскрывает выбранные поля, остальные устройства видят только раскрытые значения и список скрытых полей.
- Принятие правил: все участники должны нажать "Принять правила" перед стартом механики.
- Цель партии: общая цель видна до старта и во время обсуждения, чтобы спор шёл не абстрактно, а под конкретный сценарий.
- Спец-карта: добавлена как отдельное поле карточки, её можно скрывать или раскрывать.

## Запись по участникам

| Участник | Режим "телефон на стол" | Режим "вскрытие по очереди" |
| --- | --- | --- |
| Ведущий | Видит предупреждение в настройках, стартует раунд, принимает правила, открывает свою карточку. По умолчанию показаны профессия и возраст, остальные поля скрыты. | Ходит первым, открывает свою карточку и раскрывает только выбранные поля. Остальные видят скрытые поля без значений. |
| Аня | Принимает правила, открывает личную карточку на своём устройстве, решает что показать компании. | После хода ведущего видит его раскрытые поля. В свой ход раскрывает профессию и возраст. |
| Борис | Поведение такое же: личная карточка не утекает на чужие устройства. | Видит общий список раскрытий и в свой ход добавляет выбранные поля. |
| Вера | Может держать поля закрытыми до обсуждения. | Видит, какие поля другие игроки оставили скрытыми, но не видит значения. |
| Глеб | После готовности всех игроков попадает в общее обсуждение. | После очереди всех игроков обсуждение показывает список публичных карточек. |

## Найденные и внесённые правки

- Добавлена цель партии в модель раунда и интерфейс.
- Добавлена спец-карта в карточку игрока.
- Добавлены тематические content pack id: classic, hard_medical, party18, corporate, space, mystic, wasteland.
- Добавлены черновые цены и tier для паков, чтобы позже связать их с магазином.
- Исправлен досрочный старт голосования: для Бункера теперь инициализируется список запросов на голосование.
- Обновлены скриншоты демо-папки под новые режимы.

## Монетизация

- Free: классический Бункер, два режима вскрытия, базовые карточки, реклама только в паузах.
- Разовые паки: 99-149 ₽ за тематический набор. Самые сильные кандидаты: "Жёсткие болезни", "Космос", "Мистика", "18+ вечеринка".
- Bundle: "Все паки Бункера" за 399-499 ₽.
- PRO: отключение рекламы для всей комнаты, доступ к части премиум-паков, кастомные темы комнаты.
- Party Pass: временный пропуск на вечер, отключает рекламу и открывает все паки в одной комнате.

## Следующая итерация

- Подвязать права владения паками к магазину и профилю.
- Добавить экран выбора/описания паков до старта, чтобы игроки понимали настроение сценария.
- Дать спец-картам реальные кнопки применения, а не только текстовый эффект.
- Добавить быстрый режим на 10-15 минут с ограниченным числом раундов.
