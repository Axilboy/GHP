# 30.06.2026 - v0.4.0: MVP Бункера

Актуальный набор скриншотов Бункера после добавления двух режимов вскрытия, принятия правил, цели партии, спец-карт и публичных раскрытий.

1. Лендинг Бункера.
2. Лобби и настройки ведущего.
3. Принятие правил и цель партии.
4. Режим "телефон на стол".
5. Обсуждение катастрофы, убежища и цели.
6. Голосование совета.
7. Режим "вскрытие по очереди".
8. Общий список раскрытых карточек.
