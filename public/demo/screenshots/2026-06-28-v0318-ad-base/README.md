# v0.3.18 - база рекламы

Что изменено:

- Добавлен внутренний слот `lobby_player_banner` для маленького баннера в лобби у игроков-нехостов.
- Рекламная пауза перед стартом и следующим раундом переведена на 5 секунд.
- Вместо прямой привязки к одной рекламной сети показывается аккуратная внутренняя заглушка.
- Правило PRO/PRO+/пропуска компании сохранено: если доступ есть хотя бы у одного игрока комнаты, реклама отключается для всех.
