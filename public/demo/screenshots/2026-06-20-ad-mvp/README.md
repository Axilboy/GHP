# 20.06.2026 - рекламная модель Free/PRO

Что сделано:

- Добавлена серверная политика рекламы комнаты `adPolicy`.
- Free-комнаты получают места показа: перед стартом, между раундами, нативный блок в лобби.
- Если хотя бы один игрок в комнате имеет PRO, PRO+ или активный пропуск компании, реклама отключается для всей комнаты.
- В лобби добавлена карточка статуса рекламы.
- Добавлена заглушка рекламной паузы перед стартом и между раундами.
- Подключен первый блок РСЯ `R-A-19473963-1` внутри рекламной паузы.
- Если РСЯ не отрисовала блок, пользователь видит fallback "Реклама загружается".
- В активной игре реклама не показывается: нет рекламы на роли, обсуждении, голосовании и угадывании локации.

Почему так:

- Постоянный нижний баннер в активной игре может мешать кнопкам и раздражать игроков.
- Реклама в паузах безопаснее: она не ломает таймер, обсуждение и голосование.
- Правило "один PRO убирает рекламу всем" делает подписку полезной для всей компании.
