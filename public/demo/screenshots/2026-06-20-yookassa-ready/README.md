# 20.06.2026 - подготовка сайта к ЮKassa

Что сделано:

- Добавлены публичные страницы `/contacts` и `/refund`.
- Расширена страница `/terms`: теперь это пользовательское соглашение и оферта для цифровых товаров.
- В магазине явно описано, что товары цифровые и выдаются автоматически в профиль после оплаты.
- В футер добавлены ссылки на контакты, возвраты, политику и оферту.
- В демо-страницу добавлена отдельная папка скриншотов для проверки.

Важно перед отправкой в ЮKassa:

- Владелец должен заполнить реальные реквизиты продавца: ФИО или название, ИНН, адрес или город.
- Эти данные нельзя подставлять автоматически или придумывать.

Проверки:

- `npm.cmd test`
- `npm.cmd run build`
- `npm.cmd run test:auto`
