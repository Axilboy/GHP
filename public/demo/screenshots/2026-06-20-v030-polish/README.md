# 20.06.2026 - релиз v0.3.0: Шпион, главная и магазин

Версия: `v0.3.0`

## Что изменено

- В интерфейсе добавлена версия релиза.
- Главная стала больше похожа на публичную продуктовую страницу: понятнее, что уже работает и зачем нужен сервис.
- Страница игры "Шпион" усилена описанием возможностей и правилами.
- Магазин переписан без ощущения черновика: нормальный каталог наборов, PRO и пропуска компании.
- Рекламная пауза теперь выглядит как пользовательский экран, без внутренних упоминаний рекламной сети.
