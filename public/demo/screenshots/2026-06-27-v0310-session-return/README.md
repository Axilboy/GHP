# v0.3.10 - мягкий выход и возврат в сессию

Что проверено:

- при уходе из лобби через меню появляется кастомная модалка подтверждения;
- после подтверждения игрок попадает на выбранную страницу, а под шапкой появляется плашка возврата на 5 минут;
- кнопка "Вернуться" открывает комнату обратно без повторного ввода кода.

Скриншоты:

- `01-exit-confirm-modal.png` - подтверждение ухода из комнаты;
- `02-return-banner-store.png` - плашка возврата на странице магазина;
- `03-returned-to-room.png` - успешный возврат в комнату.
