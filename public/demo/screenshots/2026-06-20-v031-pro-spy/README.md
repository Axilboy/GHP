# 20.06.2026 - релиз v0.3.1: PRO-статус и лендинг Шпиона

Версия: `v0.3.1`

## Что изменено

- Активная PRO/PRO+ подписка показывается в шапке, профиле и меню игрока.
- У PRO/PRO+ игрока над аватаркой отображается корона.
- В профиле указано точное время, до которого активна подписка.
- В магазине при активной подписке скрывается блок продажи PRO/PRO+ и показывается активный статус.
- Блок добавления собственных словарей убран из профиля игрока.
- Конструктор собственных словарей явно помечен как функция только для игры "Шпион".
- На карточках магазина кнопки покупки показывают цену; подробности открываются нажатием на саму карточку.
- Лендинг `/games/spy` усилен как самостоятельная страница для продвижения Шпиона.

## Проверки

- `npm.cmd test`
- `npm.cmd run build`
- `npm.cmd run test:auto`
