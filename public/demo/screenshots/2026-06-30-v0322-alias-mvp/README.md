# Alias MVP

Скриншоты первого рабочего MVP игры Alias.

- `01-alias-landing-mobile.png` - мобильный лендинг Alias с запуском комнаты.
- `02-alias-rules.png` - короткие правила перед первой игрой.
- `03-alias-lobby.png` - лобби с кодом, автокомандами, таймером и целью.
- `04-alias-turn.png` - игровой ход: слово, таймер, угадали/пас.
- `05-alias-result.png` - итог хода и командный счет.
- `06-alias-landing-desktop.png` - десктопный лендинг Alias.

Сценарий: хост создает Alias-комнату, три игрока входят по коду, игроки готовы, хост запускает ход, отмечает одно угаданное слово и один пас, затем завершает ход.
