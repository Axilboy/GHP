# 20.06.2026 - релиз v0.3.2: интерфейс без XP

Версия: `v0.3.2`

## Что изменено

- XP скрыт из шапки, меню игрока, профиля, магазина и списка недавних игр.
- Блок уровня и ежедневных задач убран из профиля, пока у прогресса нет понятной игровой ценности.
- Серверные поля XP сохранены для будущей механики прогресса и совместимости тестов.

## Проверки

- `npm.cmd test`
- `npm.cmd run build`
- `npm.cmd run test:auto`
